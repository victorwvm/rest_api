# Simple Films API 

A simple REST API built in Go using Gin, with mocked data. This project was created for study and practice purposes only.

---

## Technologies

* Go
* Gin

---

## Endpoint

**GET /films**

```
http://localhost:8080/films
```

Returns a list of movies in JSON format.
