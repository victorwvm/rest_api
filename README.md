# Simple Films API 

API REST simples feita em **Go** usando **Gin**, com dados mockados.
Projeto criado apenas para **estudo e prática**.

---

## Tecnologias

* Go
* Gin

---

## Endpoint

**GET /films**

```
http://localhost:8080/films
```

Retorna uma lista de filmes em JSON.

---

## Como rodar

```bash
go run main.go
```
